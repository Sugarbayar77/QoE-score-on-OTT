# QoE-score-on-OTT
This is an website which is connecting it to mux or bitmovin. Then Mux and Bitmoving will show some information of performance of your video player and network.  

# MUX test
You need to create a demo environment on mux.com. Then you will find an environment key in settings of your dashboard. Change MUX_ENV_KEY variable by your environment key. You can change website design and videos by your own web.

# Bitmoving test
Also, you need to log in to bitmovin then you can find license-key in licenses in observability of your dashboard and API key in your account profile. Change ANALYTICS_KEY variable by your license key and PLAYER_KEY variable by your API_KEY.
